Resistor
========

The **Resistor** is a fundamental passive component in the DSpice Basic library, used to model electrical resistance within analog circuits. It is based on the standard SPICE resistor model and leverages the ngspice simulation backend for accurate DC, AC, and transient analysis.

Symbol
------

The schematic symbol for the Resistor follows the IEEE/ANSI standard zigzag representation. 
.. image:: resistor.png
   :alt: Resistor Symbol
   :align: center
 

Description
-----------

A resistor opposes the flow of electric current, converting electrical energy into heat. In DSpice, the resistor element is defined primarily by its resistance value in Ohms (Ω). Key characteristics include:

- **Linear Behavior:** Follows Ohm's Law (V = I × R) under normal operating conditions.
- **Passive Component:** Does not require an external power source to function.
- **Temperature Dependence:** Supports modeling of resistance variation with temperature using coefficients.
- **Noise Modeling:** Automatically includes thermal noise in AC and transient simulations when enabled.

The resistor is essential for voltage division, current limiting, biasing, and impedance matching in circuit design.

Netlist Format
--------------

In the SPICE netlist generated by DSpice, the resistor is represented using the following syntax:

.. code-block:: text

   R<name> <node+> <node-> <value> [TC=tc1,tc2]

Where:

- ``R<name>``: Unique identifier starting with 'R' (e.g., R1, R_LOAD).
- ``<node+>``: Positive terminal node number or name.
- ``<node->``: Negative terminal node number or name.
- ``<value>``: Resistance value in Ohms. Suffixes like 'k' (kilo), 'M' (mega), or 'm' (milli) are supported.
- ``[TC=tc1,tc2]``: Optional temperature coefficients. ``tc1`` is the linear coefficient, and ``tc2`` is the quadratic coefficient.

Example:

.. code-block:: text

   R1 1 2 10k
   R_SENS out 0 1k TC=0.0039,0.0

This format ensures full compatibility with ngspice and allows seamless integration into larger circuit netlists.

Advanced Parameters & Symbol Modification
-----------------------------------------

DSpice supports advanced simulation studies through optional parameters that can be added directly to the component symbol. This feature allows users to customize component behavior without altering the global model library.

Adding Temperature Coefficients
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

To perform temperature-dependent analysis, you can modify the Resistor symbol to expose ``TC1`` and ``TC2`` parameters:

1. **Open Symbol Editor:** Right-click the Resistor symbol in your schematic and select "Edit Symbol" or access it via the Basic library manager.
2. **Add Parameters:** In the symbol properties panel, add new parameter fields named ``TC1`` and ``TC2``.
3. **Map to Netlist:** Ensure these parameters are mapped to the SPICE ``TC`` attribute in the netlist generation settings.
4. **Save & Use:** Save the modified symbol. When placed in a schematic, you can now enter specific temperature coefficients directly in the component's property dialog.

The resistance at temperature *T* is calculated as:

.. math::

   R(T) = R_{nominal} \times [1 + TC1 \times (T - T_{nom}) + TC2 \times (T - T_{nom})^2]

Where :math:`T_{nom}` is the nominal temperature (typically 27°C).

Use Cases
~~~~~~~~~

- **Sensor Simulation:** Modeling thermistors or RTDs with precise temperature curves.
- **Thermal Stability Analysis:** Evaluating circuit performance across industrial temperature ranges (-40°C to +85°C).
- **Precision Circuits:** Compensating for drift in high-accuracy measurement systems.

.. note::
   Modified symbols are stored locally in your project workspace. To share them across projects, export the symbol to the global DSpice library using the "Export to Library" option in the Symbol Editor.
