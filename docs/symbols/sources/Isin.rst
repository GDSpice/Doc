Sin Current Source
==================

The **Sin Current Source** is an independent time-varying current source in the DSpice Sources library. It generates a sinusoidal current waveform and is essential for AC analysis, frequency response testing, and transient simulations of analog circuits. It leverages the ngspice ``SIN`` function within the ``I`` source model.

Description
-----------

A Sin current source produces a time-varying sinusoidal output defined by DC offset, amplitude, frequency, phase, and optional damping characteristics. Key characteristics include:

- **Time-Varying Output:** Generates a continuous sinusoidal current waveform for transient analysis.
- **Configurable Parameters:** Supports DC offset, amplitude, frequency, delay, damping factor, and phase shift.
- **AC Analysis Role:** Often used as the stimulus for frequency sweep (AC analysis) to determine circuit impedance and transfer characteristics.
- **Transient Analysis:** Essential for observing circuit behavior over time with realistic AC current signals.

The Sin current source is widely used in RF design, filter characterization, sensor simulation, and small-signal analysis.

Netlist Format
--------------

In the SPICE netlist generated by DSpice, the Sin current source is represented using the following syntax:

.. code-block:: text

   I<name> <node+> <node-> SIN(Ioffset Iamplitude freq Td Theta Phase)

Where:

- ``I<name>``: Unique identifier starting with 'I' (e.g., I1, I_SIG, I_AC).
- ``<node+>``: Positive terminal node number or name (current exits this node).
- ``<node->``: Negative terminal node number or name (current enters this node).
- ``SIN(...)``: Keyword specifying sinusoidal waveform with the following parameters:
  - ``Ioffset``: DC offset current in Amperes (the center value of the waveform).
  - ``Iamplitude``: Peak amplitude of the sine wave in Amperes.
  - ``freq``: Frequency in Hertz (Hz).
  - ``Td``: Delay time in seconds before the sine wave starts (default: 0).
  - ``Theta``: Damping factor in 1/seconds (default: 0, no damping).
  - ``Phase``: Phase shift in degrees (default: 0).

Examples
~~~~~~~~

**Example 1: Basic 50 Hz AC Current Source**

The image above shows a Sin current source configured as ``SIN(0 10 50)``:

.. code-block:: text

   I1 1 0 SIN(0 1 50)

This generates:
- **DC Offset:** 0 A (centered around zero)
- **Peak Amplitude:** 1 A (peak-to-peak current = 2 A)
- **Frequency:** 50 Hz
- **Period:** T = 1/f = 1/50 = 20 ms

The resulting waveform is:

.. math::

   I(t) = 10 \times \sin(2\pi \times 50 \times t) = 10 \times \sin(100\pi t)

**Example 2: Biased Small-Signal Current**

.. code-block:: text

   I_SIG in gnd SIN(1m 0.1m 50k 0 0 90)

This generates:
- **DC Offset:** 1 mA (biasing current)
- **Peak Amplitude:** 0.1 mA (small AC signal)
- **Frequency:** 50 kHz
- **Phase Shift:** 90° (cosine waveform)

**Example 3: Damped Current Oscillation**

.. code-block:: text

   I_DAMP node1 node2 SIN(0 5m 1k 1m 100 0)

This generates:
- **DC Offset:** 0 A
- **Peak Amplitude:** 5 mA
- **Frequency:** 1 kHz
- **Delay:** 1 ms (waveform starts after 1 ms)
- **Damping Factor:** 100 (exponentially decaying amplitude)

The current waveform is calculated as:

.. math::

   I(t) = I_{offset} + I_{amplitude} \times \sin\left(2\pi \times freq \times (t - T_d) + \frac{\pi \times Phase}{180}\right) \times e^{-(t - T_d) \times \Theta}

for :math:`t \geq T_d`, and :math:`I(t) = I_{offset}` for :math:`t < T_d`.

This format ensures full compatibility with ngspice and allows seamless integration into larger circuit netlists.

Advanced Parameters & Symbol Modification
-----------------------------------------

DSpice supports advanced simulation studies through optional parameters that can be added directly to the component symbol. This feature allows users to customize source behavior without altering the global model library.

Adding Parallel Resistance (Rpar)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

To model a non-ideal current source with finite output impedance, you can modify the Isin symbol to expose the ``Rpar`` parameter:

1. **Open Symbol Editor:** Right-click the Sin Current Source symbol in your schematic and select "Edit Symbol" or access it via the Sources library manager.
2. **Add Parameter:** In the symbol properties panel, add a new parameter field named ``Rpar``.
3. **Map to Netlist:** Ensure this parameter is mapped to the SPICE ``Rpar`` attribute in the netlist generation settings.
4. **Save & Use:** Save the modified symbol. When placed in a schematic, you can now enter a specific parallel resistance value directly in the component's property dialog.

The effective output current becomes:

.. math::

   I_{load} = I_{sin}(t) \times \frac{R_{par}}{R_{par} + R_{load}}

Where :math:`R_{load}` is the impedance of the connected circuit. As :math:`R_{par} \to \infty`, the source approaches ideal behavior.

Use Cases
~~~~~~~~~

- **RF Circuit Testing:** Injecting sinusoidal currents to test impedance matching networks and antenna circuits.
- **Sensor Simulation:** Modeling AC current-output sensors such as current transformers or Hall effect sensors.
- **Filter Characterization:** Sweeping frequency to determine cutoff frequencies and bandwidth of current-mode filters.
- **Small-Signal Analysis:** Providing AC test stimuli for determining transfer functions and gain.
- **Power Electronics:** Simulating ripple currents in inductors and capacitors of switching converters.
